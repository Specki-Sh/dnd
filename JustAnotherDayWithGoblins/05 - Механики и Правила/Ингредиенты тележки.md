# 🏺 Ингредиенты в тележке алхимика

В повозке на [[5 - Пятак и тележка алхимика|Пятаке]] содержится демонстрационный набор алхимика: 9 сосудов в соломенных ящиках и 1 скрытый флакон с катализатором.

---

## 📋 Каталог сосудов

| Номер | Тара | Внешний вид и свойства |
| :---: | :--- | :--- |
| **《0》** | Большая стеклянная бутыль | Абсолютно прозрачная, чистая жидкость без запаха и вкуса. Служит базовым растворителем. |
| **《1》** | Глиняная колба | Густая маслянистая жидкость со слегка желтоватым оттенком и отчетливым запахом льна. |
| **《2》** | Стеклянная пробирка в чехле | Густая темно-зеленая, почти черная смолистая жижа, издающая тошнотворный запах разложения. |
| **《3》** | Маленькая стеклянная бутылочка | Зелено-коричневая эссенция со слабым землистым грибным запахом. |
| **《4》** | Маленькая баночка | Мелкая, светящаяся ярко-оранжевая пыльца, прилипающая к пальцам. |
| **《5》** | Тонкий стеклянный флакон | Ярко-красная жидкость с приятным крепким ароматом выдержанного ликера, вишни и темного шоколада. |
| **《6》** | Большой стеклянный флакон | Мутная непрозрачная жидкость с видимым белесым осадком на дне, взметающимся при взбалтывании. |
| **《7》** | Стеклянный пузырек | Маслянистый раствор с мельчайшим серебристым порошком, вспыхивающим искрами при резком встряхивании. |
| **《8》** | Стеклянная колба | Пульсирующая ярко-розовая эссенция, мягко светящаяся в полумраке, со слабым грибным запахом. |
| **《9》** | Хрустальный флакон *(в тайнике!)* | **Универсальный катализатор:** Переливается всеми цветами радуги, испускает мистическое сияние. Способен многократно усиливать любой состав! |

---

## 💡 Подсказки для игроков
* Раздайте игрокам заметку **[[Список найденных ингредиентов]]** (в ней скрыты скрытые механические свойства и даны только визуальные описания).
* Разгадать формулы можно через **[[Записная книжка алхимика|записную книжку алхимика]]**, найденную у [[Скряб (Гоблин-грамотей)|Скряба]].
