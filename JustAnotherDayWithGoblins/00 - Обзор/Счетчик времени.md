## ⏳ Стоимость действий персонажей

| Действие | Расход времени |
| :--- | :---: |
| Перемещение между ключевыми локациями лагеря | **1 очко** |
| Поход на Поляну и обратно (через колючий кустарник) | **2 очка** |
| Попытка смешивания зелья у тележки | **1 очко** |
| Тщательный обыск шатра / кузницы / погреба / псарни | **1 очко** |
| Боевое столкновение или погоня | **1 очко** |
| Короткий отдых (Short Rest) | **2 очка** |
| Ремонт частокола на псарне / зачистка погреба от крыс | **1 очко** |
