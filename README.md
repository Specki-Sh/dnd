# D&D Obsidian Vaults Library 🎲⚔️

Коллекция модулей и приключений для Dungeons & Dragons (D&D 5e), организованных в виде автономных хранилищ (**Vaults**) для приложения **Obsidian**.

---

## 🏛 Концепция и архитектура

Каждая директория в корне репозитория представляет собой **отдельное, полностью автономное приключение (Obsidian Vault)**.

### Почему отдельные хранилища для каждого модуля?
* **Изоляция контента:** Заметки, НИП и монстры одного ваншота или кампании не смешиваются с другими.
* **Автономность:** Каждое приключение содержит свои карты, раздатки, бестиарий и настройки интерфейса.
* **Удобство Мастера (DM):** Перед игрой достаточно открыть конкретную папку модуля в Obsidian и получить чистую, готовую к сессии рабочую среду без лишнего информационного шума.

---

## 📁 Стандартная структура хранилища приключения

Каждое приключение внутри своей папки строится по единому стандарту:

```text
[Название_Приключения]/
├── .obsidian/                    # Настройки Obsidian, предустановленные плагины и CSS-стили
├── source/                       # Исходные файлы: официальный PDF, оригиналы карт, доп. материалы
├── _Ассеты/                      # Карты и иллюстрации, отображаемые внутри заметок
├── 00 - Обзор/                   # Дашборд Мастера, счетчик времени/событий, Canvas-схема
├── 01 - Сюжет/                   # Главы, фабула, зацепки, перемещение и финал
├── 02 - Локации/                 # Интерактивные карты (Leaflet) и подробные описания зон
├── 03 - НИП/                     # Досье персонажей: характер, мотивы, диалоги, тайны
├── 04 - Бестиарий/               # Статблоки монстров (Fantasy Statblocks + Dice Roller)
├── 05 - Механики и Правила/      # Уникальные механики (алхимия, болезни, кастомные правила)
├── 06 - Раздаточный материал/    # Записки, страницы дневников, карты для игроков
└── 07 - Заметки Мастера/         # Шаблоны журналов сессий, трекер инициативы, черновики
```

## 🚀 Быстрый старт: Как открыть приключение

1. Установите **[Obsidian](https://obsidian.md/)** (если еще не установлен).
2. Запустите Obsidian.
3. В окне выбора хранилища нажмите **«Открыть папку как хранилище»** (*Open folder as vault*).
4. Выберите папку интересующего вас приключения (например, `JustAnotherDayWithGoblins`).
5. Хранилище уже содержит все настроенные плагины, стили и горячие ссылки. Откройте стартовую заметку **`00 - Обзор/00 - Дашборд Мастера`**.

## 🧩 Ключевые плагины и возможности

В каждое хранилище встроены и сконфигурированы следующие инструменты:

| Плагин | Назначение |
| :--- | :--- |
| **Dataview** | Автоматическая генерация таблиц НИП, локаций, предметов и квестов по тегам и свойствам. |
| **Fantasy Statblocks** | Отображение красивых статблоков существ D&D 5e с интерактивными бросками прямо в тексте. |
| **Dice Roller** | Интерактивные броски костей прямо в заметках (например, \`dice: 1d20+4\`) и кликабельные таблицы случайных событий. |
| **Obsidian Leaflet** | Интерактивные карты с маркерами и всплывающими подсказками со ссылками на заметки комнат/зон. |
| **Advanced Tables** | Быстрое редактирование и форматирование markdown-таблиц. |
| **Obsidian Canvas** | Наглядная ментальная карта и визуальная схема переходов между локациями модуля. |

## 🎨 D&D Callout-блоки

Хранилища поддерживают специализированные стилизованные врезки:

* `> [!read-aloud]` — художественный текст для зачитывания игрокам вслух.
* `> [!dm-note]` — скрытые заметки и тактические советы для Мастера.
* `> [!loot]` — найденные сокровища, трофеи и магические предметы.
* `> [!warning]` / `> [!danger]` — ловушки, опасности и болезни.
* `> [!check]` — проверки навыков со Сложностью (DC).

## 📚 Каталог приключений

### 1. [JustAnotherDayWithGoblins](./JustAnotherDayWithGoblins/) — «Обычный день с гоблинами»
* **Формат:** Ваншот / Мини-песочница на 2–4 часа.
* **Уровень персонажей:** 2-й уровень (3–5 персонажей; отлично подходит для игры самими гоблинами!).
* **Суть:** Лагерь гоблинов захватил тележку странствующего алхимика с катализатором и ингредиентами. Пока гоблины пытаются варить безумные зелья, лагерь тайно саботируют агенты Жентарима, а окрестные бешеные звери готовятся к атаке.
* **Ключевые фичи хранилища:**
  - Полный каталог 10 рецептов гоблинских зелий и 9 ингредиентов;
  - Интерактивная карта лагеря с пинами ключевых зон;
  - Стилизованные статблоки всех уникальных монстров и НИП с формулами Dice Roller;
  - Счетчик времени суток (динамические события день/вечер/ночь);
  - Записная книжка алхимика в виде раздаточного материала для игроков;
  - Canvas-схема лагеря.

## 🛠 Добавление нового приключения

Чтобы создать новое приключение в проекте:
1. Создайте в корне проекта новую папку (например, `CurseOfStrahd` или `LostMineOfPhandelver`).
2. Скопируйте папку `.obsidian/` из настроенного модуля (например, `JustAnotherDayWithGoblins/.obsidian`), чтобы сразу получить все плагины и стили.
3. Поместите исходные материалы в подпапку `source/`.
4. Разложите материалы по стандартным папкам (`00 - Обзор`, `01 - Сюжет`, `02 - Локации` и т.д.).
5. Добавьте краткую информацию о модуле в этот `README.md`.
