# D&D Obsidian Vaults Library 🎲⚔️

Коллекция приключений для Dungeons & Dragons (D&D 5e / 5.5e 2024), организованных в виде автономных, чистых хранилищ (**Vaults**) для приложения **Obsidian**.

---

## 🏛 Концепция и архитектура

Каждая папка приключения в репозитории является **полноценным автономным Obsidian Vault**:
* **Единый мастер-файл:** Весь сюжет, таймлайн, описания локаций, диалоги и бестиарий собраны в одном интерактивном мастер-документе. Мастеру не нужно прыгать по десяткам папок во время игры.
* **Кастомный плагин D&D 5.5e (2024 Player's Handbook):** Специально разработанный для хранилища плагин `dnd-55e-sheet` отрисовывает аутентичный 3-колоночный бланк редакции 2024 года с встроенными в характеристики спасбросками, блоком *Heroic Inspiration*, механикой *Weapon Mastery* и кликабельными бросками кубиков.
* **Чистый YAML без верстки и HTML:** В заметках нет ни единого тега `<div>` — персонажи задаются простыми структурированными свойствами.
* **Интерактивность:** Клик по любой характеристике, навыку, спасброску или атаке моментально делает бросок кубиков с разбивкой результата. Кружки хитов, костей отдыха, ячеек магии и спасбросков от смерти интерактивно переключаются по клику.
* **Отдельная папка «Для печати (ЧБ)»:** Готовые материалы в формате А4 с высокой контрастностью и экономией чернил для быстрой домашней печати или экспорта в PDF через `Cmd + P`.

## 🖨 Как печатать материалы (Экспорт в PDF)

Каждая заметка в папке **`Для печати (ЧБ)/`** оптимизирована под формат **A4**:
1. Откройте нужный файл в Obsidian (например, *«01 - Бланк - Гриз (Воин 2 ур)»*).
2. Нажмите сочетание клавиш **`Cmd + P`** (или `Ctrl + P` на Windows).
3. Введите **«Экспорт в PDF»** (*Export to PDF*).
4. Выберите размер бумаги **A4** и сохраните файл. Стили плагина автоматически инвертируют цвета в четкий черный цвет на белом фоне без заливки.

## 📚 Модули в библиотеке

### 🏹 [JustAnotherDayWithGoblins](./JustAnotherDayWithGoblins/) — «Обычный день с гоблинами»
* **Формат:** Ваншот / Приключение на 2–3 часа.
* **Уровень партии:** 2-й уровень (3–5 игроков; готовы 5 прегенов-гоблинов редакции 5.5e).
* **Сюжет:** Гоблины захватили повозку алхимика с радужным Катализатором №9. Пока лагерь пробует варить зелья, шпионы Жентарима устраивают саботаж (отравленный обед, подпиленные точила, бешеные волки), а ночью лагерь штурмует зараженный бешенством бурый медведь.
* **Мастер-документ:** [Приключение - Обычный день с гоблинами.md](./JustAnotherDayWithGoblins/Приключение%20-%20Обычный%20день%20с%20гоблинами.md).

## 🚀 Быстрый старт

1. Запустите **Obsidian**.
2. Выберите **«Открыть папку как хранилище»** (*Open folder as vault*).
3. Укажите папку `/Users/specki/project/dnd/JustAnotherDayWithGoblins`.
4. Откройте файл **`Приключение - Обычный день с гоблинами.md`** или любой бланк из папки **`Для печати (ЧБ)/`**.
