# D&D Obsidian Vaults Library 🎲⚔️

Коллекция модулей и приключений для Dungeons & Dragons (D&D 5e), организованных в виде автономных хранилищ (**Vaults**) для приложения **Obsidian**.

---

## 🏛 Концепция и архитектура

Каждая директория в корне репозитория представляет собой **отдельное, полностью автономное приключение (Obsidian Vault)**.

### Почему отдельные хранилища для каждого модуля?
* **Изоляция контента:** Заметки, НИП и монстры одного ваншота или кампании не смешиваются с другими.
* **Автономность:** Каждое приключение содержит свои карты, раздатки, бестиарий и настройки интерфейса.
* **Удобство Мастера (DM):** Перед сессией достаточно открыть папку конкретного приключения в Obsidian и получить готовую рабочую среду в аутентичном стиле D&D.

---

## 📁 Стандартная структура хранилища приключения

Каждое приключение строится по единому расширенному стандарту:

```text
[Название_Приключения]/
├── .obsidian/                    # Тема ITS Theme, D&D WOTC стили, предустановленные плагины
├── source/                       # Исходные файлы: оригинальный PDF, оригиналы карт, доп. материалы
├── _Ассеты/                      # Карты и иллюстрации, отображаемые внутри заметок
├── 00 - Обзор/                   # Дашборд Мастера (карточки), счетчик времени, Canvas-схема
├── 01 - Сюжет/                   # Главы, фабула, зацепки, перемещение и финал
├── 02 - Локации/                 # Интерактивные карты (Leaflet) и подробные описания зон
├── 03 - НИП/                     # Досье персонажей All-in-One (отыгрыш + встроенные боевые статблоки)
├── 04 - Бестиарий/               # Статблоки монстров (Fantasy Statblocks + Dice Roller)
├── 05 - Механики и Правила/      # Уникальные механики (алхимия, болезни, кастомные правила)
├── 06 - Раздаточный материал/    # Записки, страницы дневников, карты для игроков
├── 07 - Заметки Мастера/         # Журнал сессий, трекер инициативы, боевая памятка
└── 08 - Персонажи Игроков/       # Готовые карточки гоблинов-героев 2-го уровня (прегены)
```

## 🎨 Тематическое оформление (ITS Theme + D&D WOTC)

В хранилище предустановлена и активирована популярная тема **ITS Theme** в паре со стилем **D&D WOTC**:
* Пергаментные текстуры и фирменные винно-красные акценты официальных книг D&D 5e.
* **Dataview Cards:** Динамические списки НИП, монстров и локаций выводятся в виде стильных интерактивных карточек-плиток.
* **Специальные Callout-блоки:**
  * `> [!read-aloud]` — художественный текст для зачитывания игрокам.
  * `> [!statblock]` — аккуратная боевая карточка существа со всеми бросками.
  * `> [!dm-note]` — скрытые заметки и тактические советы Мастеру.
  * `> [!loot]` — сокровища, трофеи и магические предметы.
  * `> [!check]` — проверки навыков со сложностью (DC).
  * `> [!danger]` — ловушки, болезни и смертельные опасности.

## 🧩 Ключевые плагины хранилища

Все плагины уже встроены в папку `.obsidian/plugins` и готовы к работе без подключения к сети:

| Плагин | Назначение |
| :--- | :--- |
| **Fantasy Statblocks** | Отображение статблоков существ 5e с интерактивными параметрами. |
| **Initiative Tracker** | Полноценный трекер боя: отслеживание инициативы, раундов и хитов. |
| **Hover Editor** | Всплывающие интерактивные мини-окна при наведении курсора на ссылки заметок. |
| **Dice Roller** | Интерактивные броски кубиков прямо в тексте (например, \`dice: 1d20+4\`) и кликабельные таблицы случайных событий. |
| **Obsidian Leaflet** | Интерактивные карты зон с кликабельными маркерами переходов. |
| **Dataview** | Автоматическая генерация карточек персонажей, предметов и локаций. |
| **Advanced Tables** | Быстрое и аккуратное форматирование таблиц. |

## 📚 Каталог приключений

### 1. [JustAnotherDayWithGoblins](./JustAnotherDayWithGoblins/) — «Обычный день с гоблинами»
* **Формат:** Ваншот / Мини-песочница на 2–4 часа.
* **Уровень:** 2-й уровень (3–5 персонажей; идеально для игры самими гоблинами!).
* **Готовые прегены в `08 - Персонажи Игроков/`:**
  - **Гриз** — Гоблин-воин (Рубака с ведром на голове и скимитаром).
  - **Шмыг** — Гоблин-плут (Воришка со скрытой атакой и отмычками).
  - **Зуб** — Гоблин-следопыт (Зверолов с длинным луком и меткой охотника).
  - **Звяк** — Гоблин-чародей (Дикий шаманчик с непредсказуемыми всплесками хаоса).
  - **Дрож** — Гоблин-жрец (Фанатичный служитель Маглибиета с боевым молотом).
* **Сюжет:** Лагерь захватил повозку алхимика с Катализатором №9. Пока гоблины пытаются варить зелья, замаскированные агенты Жентарима ведут тайный саботаж, а к ночи лагерь атакуют зараженные бешенством лесные звери.

## 🚀 Быстрый старт: Как открыть приключение

1. Установите и запустите **[Obsidian](https://obsidian.md/)**.
2. Нажмите **«Открыть папку как хранилище»** (*Open folder as vault*).
3. Выберите папку приключения (например, `JustAnotherDayWithGoblins`).
4. Откройте стартовую заметку **`00 - Обзор/00 - Дашборд Мастера`**.
